# H . U . G . O
### Helpful Universal Guidance Operator

Hugo is a personal AI assistant built on Claude Sonnet with a clear design philosophy: think before speaking, use real tools to find real answers, and never pretend to know things it doesn't. Where most assistants give confident-sounding responses from static training data, Hugo reaches for the web, your documents, or deeper reasoning before committing to an answer.

---

## What Makes Hugo Different

### He actually thinks
Hugo can be configured to use Claude's extended thinking — a pre-response reasoning pass where the model works through the problem before committing to an answer. This isn't a UI gimmick; the thinking is streamed live so you can follow along. Hugo doesn't hide uncertainty and doesn't pad responses with filler.

### He uses tools proactively, not reactively
Hugo's tools aren't opt-in features you trigger with special syntax. He decides when to search the web, look up the time, or query your documents — the same way a knowledgeable colleague would just *check* something before answering, rather than guessing. He's also instructed to include at least one cross-domain analogy per conceptual explanation, which makes abstract ideas land more intuitively.

### Context never runs out
Long conversations are compressed using a rolling summary (generated by Claude Haiku) that replaces older turns once the context window approaches its limit. Hugo carries the thread of a conversation indefinitely without losing the earlier context.

### He's honest about his limits
The system prompt explicitly instructs Hugo not to speculate when a web search would give a better answer. If a question is time-sensitive, he searches. If it's in your documents, he retrieves. The goal is accuracy over the appearance of competence.

---

## Key Toolset

| Tool | Description |
|---|---|
| **Web Search** | Brave Search API. Used for real-time information: news, prices, weather, sports, anything beyond training data. Returns ranked results with titles, URLs, and descriptions. |
| **Document Search** | Hybrid retrieval over your personal knowledge base. Combines semantic vector search (pgvector HNSW) and keyword search (PostgreSQL BM25/tsvector) with configurable alpha-weighting, so both meaning and exact terms matter. |
| **Current Time** | UTC timestamp. Used when time-awareness matters for a response. |

Tools run concurrently (up to 5 in parallel), each with a 30-second timeout. Results are capped at 10KB per tool call to keep the context window efficient.

## Architecture

Hugo is split into a Next.js frontend and a FastAPI backend that communicate over a persistent WebSocket. All AI interaction is streaming — tokens appear as they are generated.

```
┌──────────────────────────────────────────────────────────────────┐
│                         Browser (Next.js)                        │
│                                                                  │
│   LoginPage   ConversationSidebar   ChatInterface   MessageList  │
│                          Zustand Store                           │
│                        WebSocket Client                          │
└────────────────────────────┬─────────────────────────────────────┘
                             │  WebSocket + REST (HTTP-only cookies)
┌────────────────────────────┴─────────────────────────────────────┐
│                         FastAPI Backend                          │
│                                                                  │
│   /api/auth/*          /api/conversations/*          /ws         │

│                                                  Handler         │

│                                         ┌────────────────────┐  │
```

### Request lifecycle

1. **Message received** over WebSocket → idempotency check (Redis) → rate limit check → persisted to DB
2. **History built** — prior turns loaded, rolling summary prepended if present, few-shot examples injected, thinking blocks stripped (model regenerates them fresh each turn)
3. **LLM call** — system prompt and tool definitions sent with Anthropic prompt cache headers; streaming begins
4. **Tokens streamed** — text deltas batched in 50ms windows before forwarding to the client; thinking deltas bypass batching and arrive immediately
5. **Tool use** — if the model decides to call tools, execution is parallelised (up to 5 concurrent); results injected back into context and the loop continues (max 5 rounds)
6. **Persist & post-process** — completed message written to DB with full token accounting; auto-title generated on the first turn; rolling summary triggered if context is growing large
7. **Done frame** sent to client with final token counts

### Cancellation

A Redis PubSub channel (`cancel:{conversation_id}`) carries cancellation signals. The backend subscribes globally and maps signals to per-conversation `asyncio.Event` objects. The agent loop and individual tools check this event, so cancellation takes effect at the earliest safe point. Partial responses are persisted with `status="cancelled"`.

## Stack

| Layer | Technology |
|---|---|
| Frontend | Next.js 14 (App Router), TypeScript, Tailwind CSS, Zustand |
| Backend | Python 3.11, FastAPI, SQLAlchemy (async), Alembic |
| AI | Anthropic Claude Sonnet (streaming, prompt cache, extended thinking) |
| Embeddings | Voyage AI (`voyage-3`, 1024-dim) |
| Web Search | Brave Search API |
| Database | PostgreSQL + pgvector (HNSW) + pg_trgm (BM25) |
| Cache / Pub-Sub | Redis — sessions, rate limiting, cancellation bus, idempotency |
| Auth | Google OAuth (One Tap) · Email/password (bcrypt) |

## Configuration

Key environment variables for the backend (`backend/.env`):

```env
# AI
ANTHROPIC_API_KEY=
ANTHROPIC_MODEL=claude-sonnet-4-5
ANTHROPIC_THINKING_BUDGET=0        # Set >0 tokens to enable extended thinking

# Tools
BRAVE_SEARCH_API_KEY=
VOYAGE_API_KEY=

# Infrastructure
DATABASE_URL=postgresql+asyncpg://hugo:hugo@localhost:5432/hugo
REDIS_URL=redis://localhost:6379/0

# Auth
GOOGLE_CLIENT_ID=
SESSION_SECRET=change-me-in-production

# Agent behaviour
MAX_TOOL_ITERATIONS=5
TOOL_TIMEOUT_SECONDS=30
ROLLING_SUMMARY_TOKEN_THRESHOLD=60000
```

Frontend (`frontend/.env.local`):

```env
NEXT_PUBLIC_GOOGLE_CLIENT_ID=
NEXT_PUBLIC_API_URL=http://localhost:8000
NEXT_PUBLIC_WS_URL=ws://localhost:8000
```
